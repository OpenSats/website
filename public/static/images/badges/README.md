The OpenSats “100% human slop” badge is provided in light and dark SVG variants and 560 × 88 PNGs (4× resolution).
The symbol uses the paths from `data/logo.svg`, in OpenSats orange.
Badge links on the website lead to https://opensats.org/slop.

Both badge variants are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
You can use and modify them freely.

Regenerate the PNGs with `node scripts/generate-badge-png.mjs`. Install Verdana
locally to match the SVG lettering.

All [Shields.io variants and markdown snippets](https://gist.github.com/dergigi/025ec1adffe2c804f1ed67026a3584d3) are available in this gist.

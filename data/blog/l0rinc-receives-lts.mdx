OpenSats is pleased to announce long-term support for [l0rinc], a
[Bitcoin Core] contributor focused on performance, maintenance, and review.

L0rinc spends much of his time measuring what makes [initial block download]
(IBD) slower on ordinary hardware. Recent examples include [IBD benchmarks]
on hard drives and [profiling Bitcoin Core] on [Raspberry Pi 4] hardware.

For one database change, l0rinc tested [write batches] at different sizes. The
merged change set the default to 32 MiB, up from 16 MiB. He has also worked
on [buffering] block and undo-data reads and writes, and [removing] an extra
coins-cache lookup.

While reviewing a [proposal] to make database file sizes configurable, l0rinc
benchmarked several sizes and questioned whether the proposed configuration
option was worth adding. He also keeps a [running list] of coins-cache
refactors, fixes, and tests being handled across separate pull requests.

With long-term support, l0rinc plans to continue this work.

OpenSats is pleased to announce long-term support for [l0rinc]
(pronounced Lawrence), a [Bitcoin Core] contributor and security researcher
focused on performance, maintenance, and review.

In his efforts to keep Bitcoin nodes practical to run on inexpensive hardware,
l0rinc spends much of his time measuring what slows [initial block download]
(IBD) on ordinary hardware.

He examines any bottlenecks across validation, memory use, storage, and P2P
networking, looking for hot code paths to optimize, redundant work to remove,
and tasks that can safely run in parallel. Recent examples include
[IBD benchmarks] on hard drives and [profiling Bitcoin Core] on [Raspberry Pi
4] hardware.

Beyond reviewing code, l0rinc runs AI-assisted security and vulnerability
scans of Bitcoin Core, `libsecp256k1`, and other related projects, looking
for resource exhaustion, node crashes, and potentially unexpected edge cases.
To keep up with the findings from AI-scans, he simplifies code, improves
testing, and fixes any shared root causes as part of ongoing maintenance
practices.

With long-term support, l0rinc plans to continue this work.

> I'm in Bitcoin for the long run, and OpenSats' support reflects the low time
  preference we share. It gives me the stability to dig into hard problems
  that take time to get right.
>
> <cite>—L0rinc</cite>

infrastructure. Thank you to the donors who make this possible.

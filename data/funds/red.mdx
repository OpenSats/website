Code RED is the pool of money OpenSats earmarks for people red teaming
critical Bitcoin software. It funds security researchers who are triaging and
probing for flaws so the industry can address critical vulnerabilities
before attackers are able to exploit them.

Token spend, tooling, and triage burn continuously. Monthly gifts keep those
budgets topped up better than sporadic top-ups. This is a prioritized track:
applications are reviewed faster than the usual grant process, and funding
can include reimbursement of past LLM token costs. If you are red teaming
Bitcoin software today, apply at [opensats.org/red](/red). You can read the
[announcement](/blog/code-red-supporting-first-responders) for more context,
and see related posts under our
[security](/tags/security) tag.

OpenSats is a US 501(c)(3) public charity, and Code RED runs inside that
structure rather than as a separate organization. Cumulative payouts, our
bylaws, and year-end reports are linked from the
[transparency page](/transparency).

Give monthly to Code RED if you want fiat flowing in on a schedule that
matches the burn: LLM tokens, tools, and the people running triage around
the clock. One-time gifts help too; recurring fiat keeps the lights on
between pledges. Donations from US taxpayers are tax deductible.

RPC stands for remote procedure call. In Bitcoin software, it usually means a request-response API that lets another program ask a node, wallet, or service to perform an action and return structured data.

[Bitcoin Core](/projects/bitcoin-core) exposes a JSON-RPC interface for tasks such as reading blockchain data, inspecting the [mempool](/topics/mempool), managing wallets, creating transactions, and broadcasting them. A wallet, dashboard, block explorer, mining tool, or automation script can use RPC calls to talk to a local node instead of relying on a third-party service.

That interface is powerful, so access control matters. An RPC endpoint can reveal wallet and node information, and wallet RPCs may be able to move funds. Operators normally bind RPC to local or private networks, use authentication, and expose only the methods an application actually needs.
